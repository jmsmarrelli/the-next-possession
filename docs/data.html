Every snapshot is stored as portable CSV and efficient Parquet. manifest.json records row counts, schemas, and build time.

Data contracts

Normalizers fail loudly when schedules or rosters are empty; feature functions assert required columns; tests cover invariants such as nonnegative travel, bounded probabilities, unique game IDs, and exactly five players in retained starter units.

Responsible use

This is an educational portfolio, not an official NBA product. Provider data remains subject to each provider’s terms. The repository caches raw responses locally but distributes analysis-ready extracts and source links. Refresh slowly and avoid parallel request bursts.

Built with Python, R, Quarto source, and public basketball data. Educational portfolio; not affiliated with the NBA or San Antonio Spurs.
